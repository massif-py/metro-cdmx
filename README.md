# Política de Privacidad

**Aplicación:** Metro CDMX (Versión 1.0).  
**Desarrollador:** Gabriel Anaya Delgado.  
**Última actualización:** 23 de agosto de 2026.

Esta Política de Privacidad describe cómo la aplicación **Metro CDMX** maneja la información de los usuarios. Nos tomamos muy en serio la privacidad y la protección de datos.

---

## 1. Recopilación y Uso de Datos

**Metro CDMX no recopila, almacena, procesa ni transmite ningún tipo de información personal de los usuarios.**

- No solicitamos registro ni creación de cuentas de usuario.
- No recopilamos identificadores únicos del dispositivo, direcciones IP ni datos de uso.
- No utilizamos cookies ni tecnologías de rastreo.

---

## 2. Permisos del Dispositivo

La aplicación está diseñada para funcionar sin necesidad de acceder a características sensibles del dispositivo:

- **Ubicación:** No se requiere ni se solicita acceso a la ubicación GPS del usuario.
- **Contactos y Archivos:** No se accede a la lista de contactos, fotos, ni al almacenamiento interno.
- **Cámara y Micrófono:** No se solicitan permisos de hardware multimedia.

---

## 3. Licencias y Componentes de Terceros

Esta aplicación utiliza la librería de código abierto **Three.js** para la renderización de gráficos 3D, distribuida bajo la [Licencia MIT](https://opensource.org/licenses/MIT). Este componente opera de forma completamente local en el dispositivo del usuario y no realiza recopilación ni envío de datos a servidores externos.

---

## 4. Cambios a esta Política

Nos reservamos el derecho de actualizar esta Política de Privacidad en cualquier momento. Cualquier modificación se reflejará en esta misma página web con la fecha de la última actualización.
